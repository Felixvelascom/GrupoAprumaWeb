# Grupo Apruma · Sitio web

Sitio estático de una sola página (`index.html`, todo incluido: imágenes, estilos y scripts).

## Publicar en Vercel
1. Sube esta carpeta a un repositorio de GitHub (index.html en la raíz).
2. En Vercel: **Add New → Project → Import** el repositorio.
3. Framework Preset: **Other**. Sin build command. Output directory: raíz (`./`).
4. Deploy.

Nota: el formulario de contacto muestra un mensaje de confirmación pero aún no envía correos; requiere conectarse a un servicio (p. ej. Formspree, Resend o una función de Vercel).
